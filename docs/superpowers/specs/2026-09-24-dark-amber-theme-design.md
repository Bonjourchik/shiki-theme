# Dark Amber — тема Shikimori для Bonjourchik

Дата: 2026-09-24 · Статус: утверждено в брейнсторме, ждёт ревью спецификации.
Утверждённые макеты: `design/mockup-design-system.html`, `design/mockup-profile.html`.
Справочник по платформе: `docs/SHIKIMORI.md` (санитайзер, `@media`-обёртка, camo, DOM).

## 1. Цель и границы

Своя тёмная тема «с нуля» для всего `shikimori.io`, которую видит владелец
(на всём сайте) и гости его профиля. Заменяет текущую Edesign + «Bronze Sunset».

Решения брейнсторма:

| Вопрос | Решение |
|---|---|
| Настроение | тёмный минимализм, но «живой»: заметные анимации |
| Акцент | янтарь `#f0a845` (вторичный `#ff7a3d` для градиентов) |
| Арт | широкий баннер над шапкой профиля, 480px, растворяется в фоне |
| Шрифты | Unbounded (ник, заголовки, цифры) + Onest (текст) |
| Охват | весь сайт, поэтапно |
| Мобильные | сразу, ≤1023px |
| «О себе» | карточки из BB-кода: интро, топ-3, ссылки |
| Доставка | публичный GitHub-репозиторий + `@import` |

В этой спецификации детально: **этап 1 (фундамент)** и **этап 2 (профиль)**.
Этапы 3 (подстраницы профиля: список, история, избранное, друзья) и 4 (страница
тайтла, форум, поиск и прочее) — отдельные итерации со своими спецификациями.

Не входит: свой JS (невозможен), замена разметки сайта, персонаж в углу,
кастомные курсоры, замена постеров.

## 2. Дизайн-система

### Токены (`src/01-tokens.css`, префикс `--bj-`)

| Токен | Значение | Назначение |
|---|---|---|
| `--bj-bg` | `#0b0d11` | фон страницы |
| `--bj-sf` | `#14171d` | карточка |
| `--bj-sf2` | `#1b1f27` | вложенная карточка |
| `--bj-sf3` | `#252a35` | треки полос, заглушки |
| `--bj-ln` / `--bj-ln2` | `#232833` / `#343a47` | границы |
| `--bj-tx` / `--bj-tx2` / `--bj-mu` | `#eceef2` / `#c9ccd4` / `#878da0` | текст: основной / вторичный / приглушённый |
| `--bj-ac` / `--bj-ac2` | `#f0a845` / `#ff7a3d` | акцент / вторичный акцент |
| `--bj-ac-s` | `rgba(240,168,69,.14)` | мягкая подложка акцента |
| `--bj-ok` / `--bj-warn` | `#5fbf77` / `#e0655a` | успех / ошибка, «брошено» |
| `--bj-r` / `--bj-r-sm` | `16px` / `10px` | радиусы |
| `--bj-ease` | `cubic-bezier(.2,.8,.2,1)` | общая кривая анимаций |
| `--bj-font` / `--bj-font-alt` | `'Onest'` / `'Unbounded'` | шрифты |

Токены сайта переопределяются на свои: `--font-main`, `--font-alt`, `--link-color`,
`--link-hover-color`, `--link-active-color`, `--headline-color`,
`--headline-background-color` и т.д.

### Типографика

- Текст — Onest 13px / 1.6; мелкий — 11–11.5px, `--bj-mu`.
- Ник — Unbounded 800, 38px; названия — Unbounded 600, 18px.
- Заголовки блоков (`.subheadline`) — Unbounded 600, 10.5px, капс, трекинг 1.6px,
  перед ними ромб акцентного цвета с мерцающим свечением.

### Шрифты (`src/00-fonts.css`)

Прямые `@font-face` на `//fonts.gstatic.com/...woff2`: подмножества cyrillic и latin,
начертания Onest 400/500/600/700 и Unbounded 500/600/700/800, `font-display: swap`.
URL берутся из CSS Google Fonts, запрошенного с современным User-Agent. Запасной
вариант — `system-ui, 'Segoe UI', Roboto, sans-serif`.

### Компоненты (этап 1, `src/20-components/`)

Каждый файл отвечает за одну группу элементов сайта:

- `menu.css` — `.l-top_menu-v2`: полупрозрачный «стеклянный» фон с blur, пункты с
  выезжающим янтарным подчёркиванием, поиск, выпадающие подменю.
- `layout.css` — `body`, `.l-page` (прозрачная; фон даёт `body`), `.l-footer`,
  точечная сетка фона, дрейфующее янтарное сияние.
- `blocks.css` — `.block`, `.subheadline`, `.cc-*`-колонки, карточки (фон `--bj-sf`,
  граница, радиус, янтарная кромка сверху, которая ярче при наведении).
- `controls.css` — кнопки (основная, вторичная, мягкая), `input`/`textarea`/`select`
  (фокус: янтарная граница плюс кольцо `--bj-ac-s`), чекбоксы, табы.
- `posters.css` — `.b-catalog_entry`, `.b-image`: радиус, подъём, наклон, блик и
  свечение при наведении.
- `comments.css` — `.b-comment`: аватар, ник, дата, цитаты, спойлеры, код.
- `misc.css` — тултипы (`.tooltip-inner`), модалки, тосты, скроллбар, выделение
  текста, `.b-nothing_here`, пагинация, теги.

Критерий этапа 1: весь сайт тёмный и читаемый. Нигде нет белых «дыр», нечитаемого
текста или сломанных контролов на главной, странице тайтла, форуме, поиске,
настройках и списках — на десктопе и на мобильных.

## 3. Профиль (этап 2, `src/30-pages/profile/`)

Область действия — `body.p-profiles-show`. Порядок блоков как на сайте, меняется
оформление и раскладка шапки. Эталон — `design/mockup-profile.html`.

| Файл | Элементы DOM | Что делает |
|---|---|---|
| `banner.css` | псевдоэлемент над `.profile-head` на всю ширину окна | арт из `--bj-art`, высота 480px, затемнение с ~45% высоты до `--bj-bg`; наезд камеры (26s), световой блик (7s); бегущий текст `--bj-ghost` (Unbounded 800, 130px, полупрозрачная заливка с затуханием, **без обводки**) |
| `head.css` | `.profile-head`, `.c-brief`, `.avatar`, `header.head h1`, `.notice`, `.profile-actions`, `.c-info`, `.c-lists-info` | сетка «аватар · ник · карточка списков»; аватар 136px с вращающимся янтарным кольцом и пульсирующим ореолом; ник с переливом; иконки-кнопки; карточка списков «стеклом» справа |
| `history.css` | `.c-history .entry` | три карточки последних тайтлов с постером, подъём при наведении |
| `stats.css` | `.b-stats_bar`, `.lifetime`, `.bar .first/.second/.third`, `.times .time.checked`, график активности | полосы заливаются при загрузке, по основной периодически пробегает блик; столбики графика растут лесенкой |
| `favourites.css` | `.cc-favourites`, `.cc-friends`, `.b-clubs` | сетка постеров, эффекты из `posters.css`; пустые состояния приглушены |
| `achievements.css` | `.block.achievements`, `.b-achievement`, `.c-image .inner`, `.border`, `.cc-franchises .b-badge`, `.cc-authors` | квадратные карточки с превью: затемнение снизу, заголовок из `attr(data-title)`, описание из `attr(data-hint)` появляется при наведении, значок уровня, полоса прогресса; рамка — цветом из разметки (`.border`); при наведении увеличение картинки и янтарное свечение; франшизы и авторы — круглые значки, которые подпрыгивают при наведении |
| `about.css` | `.about.block`, классы `bj-*` из BB-кода | сетка карточек `bj-cards`: `bj-card`, `bj-card-title`, `bj-top` (постеры с номерами 1–3), `bj-links`; мягкий янтарный блик в углу карточки, подъём при наведении |

Появление при загрузке: блоки профиля появляются лесенкой (`opacity` + `translateY`,
0.7s, задержки через `:nth-child`).

### «О себе» (`about/about.bb`)

```
[div=bj-cards]
[div=bj-card][div=bj-card-title]Привет[/div]текст[/div]
[div=bj-card][div=bj-card-title]Топ-3[/div][div=bj-top][animes ids=185,1575,431 columns=3][/div][/div]
[div=bj-card][div=bj-card-title]Ссылки[/div][div=bj-links][url=…]…[/url][/div][/div]
[/div]
```

Тексты — черновик, финал согласуется с пользователем.

Топ-3 делается штатным тегом `[animes ids=… columns=3]`: сайт сам рисует постеры
со ссылками. Номера 1–3 ставятся CSS-счётчиком на `.bj-top .b-catalog_entry`.
Если на этапе реализации разметка тега окажется неудобной, запасной вариант —
`[url=…][img]…[/img][/url]`.

## 4. Анимации (`src/40-motion.css`)

| Анимация | Где | Параметры |
|---|---|---|
| kenburns | баннер | 26s, туда-обратно, scale 1 → 1.12 |
| sweep | блик по баннеру | 7s, бесконечно |
| ghost | бегущий текст | 14s, линейно |
| drift | фоновое сияние | 18s, туда-обратно |
| spin / pulse | кольцо и ореол аватара | 6s / 3s |
| shine | ник | 5s |
| ping | точка «в сети» | 2s |
| blink | ромб заголовка | 2.6s |
| rise | появление блоков | 0.7s, один раз |
| fill / grow | полосы, график, прогресс достижений | 1–1.4s, один раз |
| hover | постеры, достижения, кнопки, пункты меню, карточки | 0.25–0.6s на `--bj-ease` |

Правила:
- анимируются только `transform`, `opacity`, `filter` и `background-position`;
- `@media (prefers-reduced-motion: reduce)` отключает всё, контент сразу видим;
- на ≤1023px фоновые циклы (kenburns, drift, ghost, sweep) выключены — экономия батареи.

## 5. Мобильные (`src/50-mobile.css`)

- ≤1023px: баннер 240px, шапка в одну колонку (аватар 96px, ник 26px, списки под ником).
- Сетки: избранное — 4 колонки, достижения — 3, «О себе» — одна колонка;
  на ≤480px избранное и достижения — 3 и 2 колонки.
- Раскладку страниц в остальном ведёт сайт; тема задаёт цвета, шрифты, радиусы.
- Сайт на ≤1023px сам делает `body { background: none !important }`, поэтому
  цвет фона темы задаётся на `html` (и дублируется на `body` для десктопа).

## 6. Доставка и конфигурация

Репозиторий: публичный `github.com/Bonjourchik/shiki-theme`. Корень — эта папка
проекта; `.superpowers/` и локальные снимки страниц — в `.gitignore`.

Поле «Внешний вид сайта»:

```css
@import url("https://raw.githubusercontent.com/Bonjourchik/shiki-theme/main/dist/theme.css");
@media all { :root {
  --bj-art: url(//i.ibb.co/…/art.jpg);
  --bj-ghost: "BONJOURCHIK";
} }
```

- Импорт скачивается сервером Shikimori и кешируется на 8 ч. После пуша кеш
  сбрасывается на `shikimori.io/tests/reset_styles_cache` (url импорта). Сброс
  обнуляет скомпилированный CSS всех стилей с этим импортом, и при следующем
  открытии страницы стиль пересобирается сам (`Style#compile!`).
- `@media all` в пользовательской части снимает автообёртку `min-width: 1024px`.
- В `dist/theme.css` есть дефолты `--bj-art` и `--bj-ghost`, поле их переопределяет.

## 7. Сборка и проверка (`tools/build.mjs`, Node.js без зависимостей)

`node tools/build.mjs` делает следующее:

1. Склеивает `src/**/*.css` по порядку имён и сгенерированные правила в `dist/theme.css`.
2. Генерирует:
   - `[data-progress="N"] { --bj-p: N% }` для N = 0…100 (прогресс достижений);
   - `.level-N` → текст значка уровня для N = 1…20.
3. Проверяет файл под санитайзер и **завершается с ошибкой**, если находит:
   - целые слова `eval|cookie|window|parent|this|javascript|vbscript|script|behavior|behaviour|expression`
     (без учёта регистра, вне комментариев), `moz-binding`, `@charset`, `<`, `&#`;
   - `@import` внутри `src/`;
   - `\` вне `content: "…"`;
   - `url(` не на `//` и не на `data:image/…;base64`.
4. Удаляет комментарии (сайт всё равно вырезает) и печатает размер.

`preview/` — локальный стенд:
- `node tools/snapshot.mjs` скачивает HTML профиля `shikimori.io/Bonjourchik`
  в `preview/snapshots/` (в git не попадает);
- `node tools/preview.mjs` отдаёт снимок, где содержимое `<style id="custom_css">`
  заменено на свежий `dist/theme.css` плюс пользовательскую часть, и пересобирает тему
  при изменении `src/`.

Приёмка каждого этапа:
1. `build` проходит без ошибок.
2. Предпросмотр проверен на ширинах 1440, 1024, 768 и 375, со скриншотами.
3. Тема запушена, кеш сброшен, проверена на живом профиле и на 3–4 других
   страницах сайта.
4. Прогон с `prefers-reduced-motion`.

## 8. Риски

- Сайт может поменять DOM: селекторы собраны в тематических файлах, а живые
  наблюдения фиксируются в `docs/SHIKIMORI.md`.
- `raw.githubusercontent.com` может стать недоступен для сервера Shikimori. Тогда
  запасной вариант — вставить `dist/theme.css` прямо в поле.
- Тяжёлый баннер: арт должен быть не больше ~500 КБ в jpg/webp, анимации — только
  на GPU-свойствах.
- Перед первой заменой сохранить полный текст текущего поля CSS (с `@import`
  Edesign) в `reference/`.
